# Graphs

## Types of Graphs
1. Undirected graph
2. Directed graph(digraph )

## Tree is a undirected graph with no cycles and also connected graph with N nodes and N-1 Edges
 
## Rooted Tree is a tree with designated root where every node either point away or point towards the root node. When edges points towards the root node then it is called in-tree(anti-arberoscence) and out-tree(arberoscence) otherwise.

## DAG (directed acyclic graphs) , these are the directed graphs with no cycles. 

## Complete Graphs is a graph where there is a unique edge between every pair of nodes.

# DFS
It allows to explore nodes and edges of the graph, and it runs with time complexity `O(V+E)`
